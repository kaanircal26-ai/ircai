# ircai

## TOZRA AI Agent

Sohbet ekranındaki **AI Agent** düğmesi görev modunu açar. Hedefi 3-5 uygulanabilir adıma ayırır; mevcut sohbet API'si, araştırma yapılandırması ve yüklenen görsel bağlamıyla desteklenen işleri tamamlamaya çalışır. Dış dünyada etkisi olan işlemler için açık kullanıcı onayı ister. Bu sürüm kendi başına dosya sistemi, e-posta, sosyal medya veya üçüncü taraf hesaplarda işlem yapmaz.

TOZRA SESLI SOHBET + AVATAR DUZELTMESI

Bu arsiv, Vercel Root Directory "./" olan GitHub deposunun kokune gore hazirlandi.
Dosyalari mevcut GitHub deposunun kokune kopyalayip degisiklikleri commit/push edin.
Vercel yeni deployment'i otomatik baslatmalidir.

Duzeltmeler:
- TozraAuth.init() eszamanli cagrilarda tek ortak Promise kullanir.
- Ilk auth yuklemesi bitmeden sesli sohbet giris kontrolu calismaz.
- Sesli sohbet butonundaki erken senkron getSession kontrolu kaldirildi.
- /avatars/ altina 8 SVG avatar eklendi.
- Service Worker cache v21 ve voice.js?v=13 ile eski dosya onbellegi gecersiz kilindi.

Canli ortam testi bu arsiv olusturulurken yapilmamistir.
